* tgr-Emacs-Wrapper

This is a wrapper that allows to call some functions from the [[https://github.com/L-Colombo/tgr][tgr]] utility from the comfort of Emacs.

** Installation and setup

This package is not (yet) in any of the official repositories.

To install it with ~use-package~, clone the repository and add to your init file something like the following:

#+begin_src emacs-lisp
(use-package tgr
  :load-path "path/to/the/repository"
  :bind (("C-c 1" . #'tgr/search)
         ("C-c 2" . #'tgr/tags-all)
         ("C-c 3" . #'tgr/tags-file)
         ("C-c 4" . #'tgr/refile)
         ("C-c 5" . #'tgr/locate))
  :init (setq tgr/tgr-directory
              "path/to/your/directory")) ;; This must be set to ensure optimal functionality!
#+end_src
